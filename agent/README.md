# Trakr 同步 agent（唯讀）

在你自己的電腦上執行，把你自己券商帳戶的成交紀錄與庫存送到 Trakr 伺服器（Level 2 券商驗證）。

## 它做什麼、不做什麼

- **只讀取。** 不下單、不改單、不取消委託、不做期貨或選擇權。每個券商 adapter 都有白名單，白名單外的 SDK 方法會在呼叫前被擋下。
- **金鑰不離開你的電腦。** 券商金鑰與憑證只在本機讀取，伺服器只收到成交與庫存數據，以及一把只能同步資料的 agent 金鑰（不是你的登入密碼）。

## 各券商的差別

| 券商 | adapter | 登入方式 | 會讀取憑證？ | 狀態 |
| --- | --- | --- | --- | --- |
| 永豐 Sinotrade (Shioaji) | `shioaji` | API key | 否 | 依公開文件撰寫，尚未用真實帳戶驗證 |
| 富邦 Neo | `fubon` | 帳號密碼 + 憑證檔 | **是**（只用於登入） | 依公開文件撰寫，尚未接上 CLI，見下方 |

### 富邦為什麼要讀取憑證

富邦的登入需要憑證（CA）檔與其密碼。憑證本身可以用來簽署交易，所以這是本專案唯一被允許載入憑證的 adapter，並且有以下限制：

- 只有 `login` / `logout` 在最外層可用。
- 股票模組只開放 `filled_history`（成交紀錄查詢）。
- 會計模組只開放 `inventories`（庫存）與 `unrealized_gains_and_loses`（未實現損益）。
- 憑證路徑與密碼不會出現在錯誤訊息、紀錄檔或帳號指紋中。
- 其他 adapter 仍然不得出現憑證相關的名稱，這由 `tests/test_readonly.py` 檢查。

## 目前的限制

- **富邦尚未接上命令列。** `fetch_snapshot` 目前停用，因為我們查過的富邦文件沒有現金餘額查詢，無法產生完整的快照（資產淨值會不正確）。在找到現金來源之前，富邦帳戶不會同步。
- **富邦的股數單位已依文件範例推定（1000 股 = 一張），尚未用真實帳戶確認。**
- **富邦成交查詢一次最多 30 天。** 首次同步只會拿到最近 30 天的成交。
- **兩家券商的 fixture 都是依文件範例寫的**，不是真實回應。
