# Trakr 使用說明書

Trakr 是台股社群交易平台：你可以追蹤其他交易員的成交與持倉，也可以公開自己的實盤績效，參與排行榜。

## 先看這三件事

1. **Trakr 只能讀取，不能下單。**我們不會、也沒有任何功能可以替你買賣股票、改單或刪單。
2. **你的券商金鑰留在你自己的電腦。**同步程式在你的電腦上執行，券商的 API Key 與 Secret Key 不會傳到 Trakr 的伺服器。伺服器只收到你的成交、庫存與現金資料。
3. **建立券商金鑰時請不要勾選下單權限。**這是最有力的保護：即使有人拿到金鑰，也下不了單。詳見第 4 節。

## 1. 兩種資料等級

| 等級 | 資料來源 | 公開內容 | 排行榜 |
|---|---|---|---|
| **Level 2 · 券商驗證**（藍色勾勾） | 同步程式透過券商 API 取得成交紀錄 | 交易、持倉、績效 | 符合資格才列入 |
| **Level 1 · 自行回報** | 你自己上傳的 CSV，沒有可信來源證明 | 只顯示交易紀錄，每筆標示「自行回報」 | 不列入 |

Level 1 適合先試用，或補登同步之前的歷史交易。Level 1 的資料**永遠不會**混進 Level 2 的績效與排行榜，就算你之後也綁了券商。

## 2. 註冊與登入

1. 打開網站，點底部最右邊的「我」。
2. 選「還沒有帳號？註冊」，填入電子郵件、**帳號 ID** 與密碼（至少 8 個字元）。

**關於帳號 ID（@id）：**

- 它是你在平台上的**唯一識別**，會公開顯示成 `@你的ID`，別人也用它找到你。
- 3 到 20 個**英文字母、數字或底線**（不能用中文、空格、句點或符號）。
- **不分大小寫**：`Alice`、`alice`、`ALICE` 視為同一個 ID，已有人使用就不能再註冊。你選的大小寫寫法會保留顯示。
- 輸入時會**即時告訴你能不能用**，有人使用、格式不對或是保留字都會當場提示。
- `admin`、`support`、`official`、`tot`、券商與證交所名稱（如 `fubon`、`twse`）等，以及 `admin` 或 `trakr` 開頭的 ID 為**系統保留**，無法註冊，避免有人冒充官方。名稱中間夾帶這些字（例如 `alice_admin`）則沒有問題。
- **註冊後無法更改**。請選一個你之後也想一直使用的 ID。
3. 之後用電子郵件與密碼登入。iPhone 會詢問是否用 iCloud 鑰匙圈儲存密碼。

目前**尚未提供**忘記密碼與電子郵件驗證，請務必記住密碼。

## 3. Level 1：匯入 CSV

在「我」頁面找到「Level 1：匯入 CSV」。

**欄位**（第一列必須是欄位名稱，中英文皆可）：

| 內容 | 可用的欄位名稱 |
|---|---|
| 時間 | 時間、日期、成交日期、成交時間、time、date |
| 股票代號 | 股票代號、證券代號、代號、symbol、code |
| 買賣 | 買賣、買賣別、side、action（「買進」「現股賣出」「buy」「sell」都可以） |
| 股數 | 股數、成交股數、qty、shares；或用「張數」「成交張數」（1 張 = 1000 股） |
| 價格 | 價格、成交價、price |
| 手續費（可省略） | 手續費、fee |

**範例：**

```csv
時間,股票代號,買賣,股數,價格,手續費
2026-11-02 09:15,2330,買進,1000,600,855
2026-11-02 10:30,2330,賣出,1000,650,925
```

- 時間視為台北時間；只寫日期時視為當天 13:30。民國年（例如 115/11/02）也可以。
- 一次最多 2000 筆。同一個檔案重複上傳不會重複計入。
- 有錯誤的列會告訴你第幾列、什麼問題，其餘正確的列照常匯入。
- 想全部重來，按「清除已匯入」。

### 持倉怎麼算出來

只有成交紀錄，只能看出對方「買過、賣過什麼」，**看不出目前持有多少股**，因為不知道起點。要顯示持倉，請在「我」頁面的「Level 1：庫存快照」上傳一次某日收盤時的庫存：

1. 選擇**庫存日期**。
2. 上傳 CSV（股票代號、股數或張數，均價可省略），或按「這天沒有任何持股」。
3. 之後匯入的成交會自動套用到這個起點上，得出目前的持倉。

- 持倉會標示「由自行上傳的庫存推算，屬 Level 1，未經券商驗證」，並標示庫存基準日。
- 上傳新的庫存時，系統會用舊的庫存加上中間的成交推算，**與你上傳的新庫存比對**。不一致會列出是哪幾檔，代表某些成交或庫存有遺漏。
- 若賣出數量超過庫存，會提示你檢查資料。
- 比重顯示模式下，自行上傳的庫存無法計算比重，因此不顯示持股。
- 自行上傳的庫存**不會**進入券商驗證的排行榜。

## 4. Level 2：券商同步

### 4.1 建立券商 API 金鑰（以永豐金證券為例）

1. 確認你有該券商的證券帳戶，並已完成券商要求的 API 服務條款簽署與測試。
2. 登入券商的 API 管理頁面，建立新金鑰。
3. 權限只勾**帳務**（查詢庫存、成交）。**不要勾「下單」。**
4. 建議同時：
   - **綁定 IP**：只允許你執行同步程式的那台電腦。
   - **設定到期日**：到期後再重新建立。
5. 立刻把 Secret Key 存到密碼管理器。券商通常只顯示一次，遺失只能刪除重辦。

> 權限選項的實際名稱以券商頁面為準，上面是我們查到的常見做法。若你的券商沒有「無下單權限」的選項，請不要使用這個功能，並聯絡我們。

### 4.2 建立 Trakr 同步金鑰

1. 在「我」頁面找到「同步金鑰」，按「建立同步金鑰」。
2. 金鑰（`tot_ak_` 開頭）**只顯示一次**，請立刻複製。
3. 這把金鑰只能上傳你的資料，**不能登入網站、不能下單**。外洩時按「撤銷」即可，同步程式會立刻停止。最多同時 5 把。

### 4.3 安裝與執行同步程式

需要 Python 3.10 以上。同步程式目前以原始碼提供，在專案的 `agent` 資料夾。

**Windows（PowerShell）：**

```powershell
cd agent
pip install .[shioaji]
$env:SHIOAJI_API_KEY = "你的券商 API Key"
$env:SHIOAJI_SECRET_KEY = "你的券商 Secret Key"
$env:TOT_AGENT_KEY = "tot_ak_..."
python -m tot_agent --broker shioaji --server https://你的網站網址
```

**macOS／Linux：**

```bash
cd agent
pip install ".[shioaji]"
export SHIOAJI_API_KEY="你的券商 API Key"
export SHIOAJI_SECRET_KEY="你的券商 Secret Key"
export TOT_AGENT_KEY="tot_ak_..."
python -m tot_agent --broker shioaji --server https://你的網站網址
```

看到 `synced:` 就表示成功。回到「我」頁面，狀態會變成「已綁定」。

想先用模擬環境練習，加上 `SHIOAJI_SIMULATION=1`。

### 4.4 同步程式做什麼、不做什麼

| 會做 | 不會做 |
|---|---|
| 登入券商讀取庫存、現金、成交 | 下單、改單、刪單 |
| 每 60 秒把這些資料送到 Trakr | 載入或啟用憑證（CA） |
| | 把券商金鑰傳給 Trakr |

程式碼設計成「白名單」：只有明確列出的讀取函式才能呼叫，其他所有券商函式（包括任何下單相關的）會在呼叫前就被擋下。想自己檢查，請看 `agent/tot_agent/adapters/`。

### 4.5 讓它持續執行

- 同步程式要**一直開著**。電腦關機或斷網期間，如果剛好在交易時段，會被記為「未驗證區間」。
- 有未驗證區間時，你會**暫時從排行榜消失 14 天**，這是為了避免「先不同步、事後挑著揭露」。
- 建議放在不會關機的電腦或雲端主機，並設定開機自動啟動。

## 5. 隱私與防狙擊

在「我」頁面的「隱私與防狙擊」：

- **交易紀錄延遲公開**：別人要等你設定的延遲之後才看得到你的成交。最短 3 分鐘，可選 3、4、5、10、30 分鐘。這個下限由伺服器強制，無法繞過。
- **持倉顯示**：完整公開（標的、股數、成本）、只顯示比重，或完全隱藏。持倉資料同樣會延遲。
- 你自己永遠看得到自己的完整資料。
- 就算持倉隱藏，你的**總報酬率與勝率**仍會顯示在排行榜上。

## 6. 排行榜規則

只列入 **Level 2** 的交易員，且要同時符合：

- 已平倉筆數與資料點達到最低門檻。
- 最近 14 天沒有未驗證區間。
- 最新的庫存與成交紀錄對得上。

**總報酬率**採時間加權，所以大額入金或提領不會讓你的報酬看起來變好或變差。**勝率**是獲利的平倉筆數除以全部平倉筆數（先進先出）。

目前**未計入**現金股利、股票股利、除權息調整與融資融券利息，所以數字可能和券商帳面略有差距。

頁面上看到「未列入排行榜：…」時，會列出原因。

## 7. 社群

- 任何人都能看，登入後才能發文與留言。內容只支援純文字，最多 500 字。
- 看到垃圾訊息、詐騙或辱罵，請按「檢舉」。同一則內容被 3 個不同的人檢舉會先自動隱藏，等待人工審核。
- 你可以刪除自己的貼文與留言。
- 討論內容僅為個人意見，不構成投資建議，請自行判斷風險。

## 8. 市場行情與自選股

首頁的「市場」分頁顯示證交所公布的**盤後資料**：加權指數、臺灣 50 等指數、全市場成交金額與量，以及當日兩份**前 20 名排行**，用排行上方的切換鈕選擇：

- **成交額**：依成交金額排序，看的是資金湧入哪些股票，通常是台積電、聯發科這類權值股。
- **成交量**：依成交股數排序，低價股與 ETF 常因股數多而靠前，不代表資金大量流入。

兩份排行看到的畫面常常差很多，建議對照著看。

「自選」分頁讓你建立自己的股票清單。

- **這不是即時行情。**資料是證交所每日收盤後公布的，頁面會標示資料日期。想看即時走勢請使用券商 App。
- **紅漲綠跌**，與台灣習慣一致。成交量以「張」顯示（1 張 = 1000 股）。
- 點任何一檔股票可以看到開盤、最高、最低、成交量、成交值與成交筆數。
- **交易紀錄與持倉都會顯示股票名稱**（例如「台積電 2330」），點名稱就能進入該股頁面。名稱取自證交所資料，證交所暫時連不上或代號查無資料時，只會顯示代號，交易紀錄本身不受影響。
- **自選股**：登入後在「自選」搜尋股票代號或名稱（例如 2330 或 台積電），按「加入」。最多 50 檔，可隨時移除。自選清單**只有你自己看得到**。
- 證交所暫時無法連線時，頁面會顯示上一次成功取得的資料並加註說明。
- 每個畫面底部都有資料來源與授權說明，這是使用政府開放資料的要求，請勿隱藏。

## 9. 個人照片

在「我」頁面直接**點大頭貼**（右下角有相機圖示），選一張圖片當大頭貼。想移除，按頭像下方的「移除照片」。

- 支援 JPEG 與 PNG。照片會在**你的手機上**自動裁成正方形並縮小到 256 像素，所以上傳很快，也不會用掉太多流量。
- 重新編碼的過程會移除照片裡的拍攝資訊，例如**拍攝位置（GPS）**與相機型號，這些不會上傳。
- 照片會顯示在你的個人頁、排行榜、社群貼文與留言旁。公開可見。
- 想換就再上傳一張；想拿掉按「移除」。
- 請只使用你自己有權使用的照片，不要使用他人肖像、不雅或違法的圖片。

### 自我介紹與社群連結

在「我」頁面的「個人簡介與社群連結」可以寫一段自我介紹，並放上你的社群帳號，別人在你的個人頁就能一鍵前往。

- **自我介紹**：最多 160 字、4 行，純文字。其中的網址不會變成可點的連結。
- **社群連結**：支援 Threads、Instagram、X、Facebook、YouTube、TikTok、Telegram、LINE，最多 6 個，同一平台只能放一個。
- **只需填帳號**，例如 `alpha.trader`。你也可以直接貼上個人頁網址，系統會自動取出帳號，並產生官方網址。
- **不開放自訂網址，也不能放群組邀請連結**（LINE 群、Telegram 群等）。這是為了避免釣魚網站與投資詐騙群，保護所有使用者。LINE 只支援「用 LINE ID 加好友」。
- 別人點連結會在新分頁開啟對應的社群 App 或網頁。
- 看到可疑的簡介或連結（拉人進群、冒充、詐騙），請在對方個人頁按「檢舉簡介」。同一個人的簡介被 3 位不同使用者檢舉，簡介與連結會先被隱藏，他本人仍看得到並可修改。

## 10. 帳號安全

- 在「我」頁面可以變更密碼；變更後其他裝置會自動登出。
- 連續輸入錯誤密碼會暫時被鎖 15 分鐘。
- 懷疑同步金鑰外洩：到「同步金鑰」按「撤銷」。若券商金鑰也可能外洩，請同時到券商的 API 管理頁面刪除該金鑰。
- 請勿把券商 Secret Key 或 Trakr 同步金鑰貼給任何人，包括客服。我們不會向你索取。

## 11. 疑難排解

| 狀況 | 可能原因與處理 |
|---|---|
| 同步程式顯示 `unauthorized` | Trakr 同步金鑰錯誤或已撤銷。重新建立一把。 |
| 顯示 `a different broker account is already linked` | 你的帳號已綁定另一個券商帳戶，**綁定後不能更換**。如需更換請聯絡我們。 |
| 顯示 `already linked to another user` | 這個券商帳戶已被別的 Trakr 帳號綁定。 |
| 券商登入失敗 | 檢查 API Key／Secret Key、IP 綁定是否包含這台電腦、金鑰是否過期、券商 API 測試是否完成。 |
| 沒出現在排行榜 | 到自己的交易員頁面看「未列入排行榜」的原因。 |
| 前面的交易沒有顯示 | 同步只從**綁定當下**開始計算，不接受補登更早的券商資料。更早的交易可以用 CSV 匯入（Level 1）。 |
| 庫存與成交不一致 | 可能是除權息、盤後零股、轉入轉出庫存或券商欄位單位差異。請聯絡我們並附上時間與股票代號。 |
| CSV 匯入失敗 | 看錯誤訊息的列號。常見原因：第一列不是欄位名稱、時間格式無法辨識、股數不是整數。 |
| 照片上傳失敗 | 只支援 JPEG 與 PNG，檔案請小於 20 MB。iPhone 的 HEIC 照片通常會自動轉換；若失敗，請先用「照片」App 匯出為 JPEG。每小時最多更換 10 次。 |
| 市場頁顯示「暫時無法取得」 | 證交所資料來源暫時連不上，稍後再試。若曾成功取得，頁面會改顯示舊資料並加註。 |
| 搜尋不到某檔股票 | 目前只收錄**上市**股票與 ETF，不含上櫃與興櫃。 |
| 股價看起來不是今天的 | 這是盤後資料，顯示的是最近一個交易日。盤中看不到即時變動是正常的。 |

## 12. 常見問題

**你們會不會幫我下單？**不會。系統沒有任何下單功能，同步程式也在程式層面擋下所有下單相關的呼叫。

**你們看得到我的總資產嗎？**同步程式會上傳現金與庫存，用來計算報酬率，因此伺服器端有這些資料。對外公開的只有報酬率曲線（以 1 為起點的指數，不是金額）、你選擇公開的持倉與延遲後的成交。請參考〈資安說明〉了解資料如何保存。

**我可以只公開績效、不公開持倉嗎？**可以，把持倉設為「完全隱藏」。

**可以刪除我的帳號與資料嗎？**目前尚未提供自助刪除，請聯絡我們處理。（這是上線前要補的功能。）

**為什麼同樣的績效，排行榜和券商 App 不一樣？**我們用時間加權報酬率與先進先出，券商可能用平均成本，也可能包含股利與利息。
